## 二、★ 最大的发现：**φ 的两个面孔**

这是两套工作**真正的合流点**，我要把它放在最前面。

### 2.1 仓库的 `φ`：来自**相生环（72°）**

`Adj(C₅)` 的特征值是 `2cos(72°k)`：

```
k=0: 2cos0°   = 2
k=1: 2cos72°  = 0.618034 = 1/φ     ← 这里
k=2: 2cos144° = −1.618034 = −φ     ← 和这里
```

**φ 之所以出现，是因为 `cos72° = 1/(2φ)`。**

### 2.2 我们的 `φ`：来自**五角星步（36°）**

我们的临界结果 `λ₁ = e^(i36°)`，其 `cos36° = φ/2`：

```
2cos36° = 1.618034 = φ             ← 我们
```

### 2.3 ★★ 二者**互为倒数**，且**角度差一倍**

| | 角度 | `2cos` |
| :-- | :-- | :-- |
| 仓库（相生环 `C₅`） | **72°** | **`1/φ`** |
| 我们（五角星步） | **36°** | **`φ`** |

```
2cos36° × 2cos72° = φ × (1/φ) = 1        （互为倒数）
36° × 2 = 72°                            （角度差一倍）
```

> **"角度差一倍"正是「旋量双覆盖」；"互为倒数"正是它的代数指纹。**
> —— 仓库的 `1/φ` 与我们的 `φ`，**是同一个东西的两面**：
> 一面是**相生圈**（72°、经典、`R⁵=I`），另一面是**五角星车步**（36°、旋量、10 步复原）。

**这也让仓库 §五"与旋量-太极的结构映射"第一次有了定量内容**：不只是"都是旋转"，而是
**`2cos36°` 与 `2cos72°` 互为倒数**——一个**可算的**对应。

## 三、★ 两个临界：**不同不可约表示上的临界**

两套工作都找到了"临界"，但**在完全不同的模上**——这非常说明问题。

| | 仓库 | 我们（05 系列） |
| :-- | :-- | :-- |
| 临界条件 | **`a + b = 1`**（生克总强度） | **`a = 1/φ, d = 1/φ²`**（相生 / 衰减） |
| 临界发生在 | **`k=0`（均匀模 / 零根）** | **`k=1`（图案模）** |
| 数学标志 | Cartan 矩阵**出现零特征值** | **`λ₁ = e^(i36°)`**（模 1，arg 36°） |
| 语义 | **"以平为期"** | **五角星步 / 旋量双覆盖** |

> **关键**：`k=0` 与 `k=1` 属于 `C₅` 的**不同不可约表示** ⟹ **两个临界互相独立、可以同时成立**。
>
> 也就是说：**五行系统可以有两个"稳定性之门"**——
> 一个管**总量平衡**（仓库的"以平为期"），一个管**相位/节律**（我们的"五角星步"）。

**而这两者在我们的构造里是协同的**：算例三发现，
**"总量饱和"恰好只作用于 `k=0`** —— 它正是仓库那个临界模的**稳定器**。
