# 算例：五角星层级步的代数验证（复盘第五步 · 行动）

**目标**：把复盘里的 ⑥ 从"结构性"推一步——为"五角星层级步"写出**代数形式**，
验证其特征值是否**精确**就是 `|λ| = 1/φ²`、`arg λ = 36°`。

---

## 一、层级步的矩阵形式

五角星的层级步 = **缩放 `q` ∘ 旋转 36°**。它是 2×2 矩阵：

```
M = q · R(36°)
```

对本结构 `q = 1/φ² = 0.381966…`：

```
M = [ +0.309017  −0.224514 ]
    [ +0.224514  +0.309017 ]
```

### 特征值（实算）

| 量 | 实算 | 理论 | 判定 |
| :-- | :-- | :-- | :-- |
| `\|λ\|` | **0.381966** | `1/φ² = 0.381966` | **精确吻合** ✓ |
| `arg λ` | **+36.000°**、−36.000° | `±36°` | **精确吻合** ✓ |

> 即 **`λ± = q·e^(±i36°)`** —— 一行代数，把"五角星层级步"的全部信息压进两个复特征值。

---

## 二、由此直接读出周期（⑤ 从“构造”升级为“代数”）

特征值 `λ = q·e^(i36°)` 说明每一步：**模 ×`q`、相位 +36°**。

| 读数 | 值 |
| :-- | :-- |
| 相位周期 | `360°/36° = ` **10**（而 `\|cos\|` 给出 **5**） |
| 幂律指数 | `ln q = −0.9624` |
| 与 §十六 的对照 | **完全一致**（实算调制周期 4.998 ≈ 5） |

> 所以 §十六 那个"构造出来"的周期 5，**不是巧合**——它就是 `arg λ = 36°` 的直接推论。

---

## 三、诚实考察：非线性会不会破坏它？

任意动力学 `F(x) = M·x + N(x)`，在不动点处 `J = M + N'(x*)`。实算：

| 非线性 | `\|λ\|` | `arg λ` | 保持？ |
| :-- | :-- | :-- | :-- |
| **无（纯层级步）** | 0.381966 | **+36.000°** | **✅ 精确保持** |
| 径向型 `N = −s\|x\|²x` | 0.264703 | +53.077° | ❌ 被移位 |
| 一般型（含切向项） | 0.406305 | +29.389° | ❌ 被移位 |

**结论**：`arg λ = 36°` 是**纯层级步**的精确性质；**一旦加非线性，一般会被移位**。
要被精确保持，需要 `N'(x*) = 0`（非线性的一阶项在不动点处消失）。

> 这是**多于一个方程**的条件 ⟹ **DSI 发生在参数空间的特殊子集上（codimension ≥ 1）**，
> 而不是"随便什么参数都会发生"。

---

## 四、这个"负面"结论，恰好解释了"临界"

把上一节翻译成物理语言：

- 一般参数下，动力学**不会**自动具有 `arg λ = 36°`；
- 必须**调参**落到特殊子集上——而在动力系统里，**这种"标度不变的特殊点"就是临界点**；
- 临界点的标度不变，本来就不是普适的，而是 **codimension ≥ 1 的现象**。

> ⟹ **"五行 = 毕达哥拉斯螺旋"若要成为动力学陈述，它必然是一条关于"临界点"的陈述**：
> 只有在系统处在**标度不变的特殊状态**（临界）时，那条对数周期才会显现。
>
> —— 这与 §十四（RG 不动点）、§十五（临界线 `a = d`）**首尾相接**。

## 六、这一步把什么推进了
