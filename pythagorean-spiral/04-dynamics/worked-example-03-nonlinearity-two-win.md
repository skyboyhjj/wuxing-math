# 算例三：两全的非线性 —— 为什么必须是“总量饱和”

**目标**：找出一种非线性，能**同时**做到（a）压住 k=0 过载、（b）保住五角星步 36°。

---

## 一、问题的结构：k=0 与 k=1 在对称性上**解耦**

- **k=0**：**均匀模**（五个分量相等）——它是唯一在 `C₅` 下**不变**的模；
- **k=1**：**图案模**（2 维旋转）——携带 36°。

> 两个模属于**不同的不可约表示** ⟹ 任何**只作用于均匀模**的非线性，**碰不到 k=1**。

这就是解题的钥匙。

---

## 二、候选 A：立方各向同性饱和 —— 会“漏”到 k=1

`N = −c·|x|²·x`（各向同性饱和）。

| 量 | 值 |
| :-- | :-- |
| 压住过载？ | ✅ 是 |
| `arg λ₁` | **42.17°（被推离 36°）** ❌ |

**原因**：`|x|²` 混合了所有模，所以它虽然压住了 k=0，也**改了 k=1 的相位**。

> **注（V10·A7）**：这个 `42.17°` **不是普适常数**——立方项对 `k=1` 的有效修正 **正比于 `c·A²`**（由 `cos³φ = (3cosφ + cos3φ)/4`），随振幅 `A`、系数 `c` 变化；`42.17°` 只是**该参数取值下**的数。

---

## 三、★ 候选 B：总量饱和 —— 两全

`N = −c·X̄·1`，其中 `X̄ = (1/5)Σx_j` 是**均值**（一个向所有分量等量施加的项）。

在模式基下：

```
J_k = (1−d) + a·ω^k      (k ≠ 0)
J_0 = (1−d) + a − c
```

**关键**：`k ≠ 0` 的谱**完全不依赖于 `c`**。

取 `a = 1/φ`、`d = 1/φ²`：

| `c` | `J_0` | `J_1` | `\|J_1\|` | `arg J_1` |
| :-- | :-- | :-- | :-- | :-- |
| 0.30 | +0.936（稳定 ✓） | — | 1.000000 | **36.0000°** |
| **0.50** | **+0.736（稳定 ✓）** | — | 1.000000 | **36.0000°** |
| 0.70 | +0.536（稳定 ✓） | — | 1.000000 | **36.0000°** |

> **两全**：`c = 0.5` 时，`J_0 = 0.736 < 1`（过载被压住），而 **`J_1 = e^(i36°)` 分毫未动**。

![非线性选择：立方饱和 vs 总量饱和](../figures/wuxing_nonlinear_choice.png)

---

## 四、物理读法

| 数学 | 物理 |
| :-- | :-- |
| `−c·X̄` 只作用于均匀模 | **总量有上限（不分五行）** |
| k≠0 谱不受 `c` 影响 | **五行之间的分配不受影响** |

> 这非常自然：**"生态的承载极限"管的是"总量"，不该管"五行怎么分"**。
> —— 反过来，`|x|²` 式饱和会同时惩罚"分配"，所以它必然扰动 36°。

---

## 五、最终方程（把 ⑥ 从“条件”推到“方程”）

```
x_i(t+1) = (1 − d)·x_i(t) + a·(Sx)_i(t) − c·X̄(t),    X̄ = (1/5)Σ_j x_j
```

**参数**：

| 参数 | 取值 | 含义 |
| :-- | :-- | :-- |
| `a`（相生） | `1/φ` | 生 |
| `d`（衰减） | `1/φ²`（＝五角星尺度 `q`） | 衰减 |
| `c`（总量饱和） | `> a − d` | 承载极限 |

**结论（谱）**：

- `λ_0 = 1−d+a−c < 1` —— **不再过载**；
- **`λ_1 = e^(i36°)`** —— **五角星步、临界、分毫未动**。

---

## 六、标注

| 主张 | 判定 |
| :-- | :-- |
| k=0（均匀）与 k=1（图案）属于不同不可约表示 | **严格** |
| 只作用于均匀模的非线性不改变 k≠0 的谱 | **严格（代数）** |
| 总量饱和 `−c·X̄` 同时压住 k=0、保住 `e^(i36°)` | **严格** |
| 立方饱和 `−c\|x\|²x` 会把 `arg λ₁` 推离 36°（**漂移量 ∝ `c·A²`**；42.17° 为该参数下的值）（V10·A7） | **严格（实算）** |
| "总量的上限 vs 五行的分配"这一物理读法 | **结构性**（自然，但属解释） |
| "五行动力学**就是**这个方程" | **结构性**（构造性建模；需实测标定 `a,d,c`） |

---

## 七、这一步把 ⑥ 推进到了哪

| 早先 | 现在 |
| :-- | :-- |
| ⑥ "五行螺旋的动力学 = 层级系统"（未知深浅） | **有了一组具体方程 + 参数** |
| "需要非线性"（模糊） | **明确了非线性的类型**：必须**只作用于总量/均匀模** |
| "五角星步与稳定不可兼得"（线性结论） | **非线性可以兼得**，且给出了判据 |

> **一句话**：**"生"给旋转、"衰减"给临界、"总量饱和"给稳定**——三者各管一件事，
> 因为它们在 `C₅` 的**不同不可约表示**上作用。**这才是"生克并行而不相害"的代数根据。**
