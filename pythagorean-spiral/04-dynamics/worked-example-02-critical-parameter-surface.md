# 算例二：五行临界参数面 —— 五角星步是相生步的“平方根”

**目标**：把 `M = q·R(36°)` 接回**具体五行耦合方程**，解出**临界参数面**。

---

## 一、C₅ 模式分解：k=1 模式就是“旋转 72°”

相生算子 `S`（步长 1 的循环置换阵）在傅里叶基下对角化，5 个模式标量为 `ω^k`（`ω = e^(i2π/5)`）：

| k | 0 | 1 | 2 | 3 | 4 |
| :-- | :-- | :-- | :-- | :-- | :-- |
| `arg ω^k` | 0° | **+72°** | +144° | −144° | −72° |

> **k=1 模式 = 一个二维旋转（72°）。** 这是"五行生"的谱像。

---

## 二、★ 五角星步 = 相生步的**平方根**

五角星层级步：`T = q·e^(i36°)`；相生步（k=1）：`e^(i72°)`。

```
T² = q² · e^(i72°)
```

即 `T²` 与相生步**只差一个实数因子 `q²`**：

> **`T` 是相生步的“平方根”（差一个尺度）。**

---

## 三、★★ 旋量双覆盖：与《旋量-太极》的“720° 复原”同构

| | 5 步后 | 10 步后 |
| :-- | :-- | :-- |
| **相生圈**（72°/步） | **360° 复原**（经典） | — |
| **五角星**（36°/步） | **180°——方向翻转（倒置）** | **360° 才复原** |

> **五角星嵌套 = 五行相生圈的「旋量双覆盖」。**
> 这与本知识库《旋量-太极模型》的**“720° 复原”**（以及“**平方根**”母题）**是同一个结构**——
> 五行的几何，竟然自带一个**旋量式的二重覆盖**。

---

## 四、★★★ 临界参数面（闭式解）

线性动力学 `λ_k = (1−d) + a·ω^k − b·ω^(2k)`。先取纯相生（`b = 0`）：

### 4.1 第一步：`arg λ₁ = 36°` 的条件

令 `c = cos72° = 0.309017`、`s = sin72° = 0.951057`，`λ₁ = (1−d+ac) + i·a·s`：

```
arg λ₁ = 36°  ⟺  a·s / (1−d+a·c) = tan36°
```

代入恒等式 `s / tan36° = 2cos²36° = 1 + c`，得 `1 − d = a`，即

> **`d = 1 − a`** —— 极简的一条线。

### 4.2 第二步：再加临界 `|λ₁| = 1`

在 `d = 1−a` 上：`|λ₁|² = a²[(1+c)² + s²] = 2a²(1+c) = φ²a²`，故 `|λ₁| = φ·a`。

```
|λ₁| = 1  ⟺  a = 1/φ
```

### 4.3 ★ 临界参数点

| 参数 | 值 |
| :-- | :-- |
| 相生 `a` | **`1/φ` = 0.618034** |
| 衰减 `d` | **`1/φ²` = 0.381966**（**恰等于五角星尺度 `q`！**） |
| 约束 | **`a + d = 1`** |
| 结果 | **`λ₁ = 0.809017 + 0.587785i = e^(i36°)`**，`\|λ₁\| = 1.0000000000` |

> **五行线性系统在 `a = 1/φ`、`d = 1/φ²`（即 `a+d=1`）时，其 k=1 模式的谱恰好是五角星步 `e^(i36°)`，且处于临界。**

## 五、诚实边界：**k=0 过载** —— 恰好就是原稿说的“只有相生会过载”

该点上全部 5 个模式：

| k | `\|λ\|` | `arg λ` | 状态 |
| :-- | :-- | :-- | :-- |
| **0** | **1.23607** | 0° | **过载（不稳定）** |
| 1 | **1.00000** | **36°** | **临界（五角星步）** |
| 2 | 0.38197 | 72° | 收缩 |
| 3 | 0.38197 | −72° | 收缩 |
| 4 | 1.00000 | −36° | 临界 |

> **`λ₀ = 2/φ ≈ 1.236 > 1`（均匀模发散）** ——
> **这正是原稿那句“只有相生（没有制约）就会过载、会崩”**！
> 原稿的直觉，在这里成了一个**具体的特征值**。

### 加相克能救吗？—— 不能两全

`b > 0` 可以把 `λ₀` 压下去，但**会把 `36°` 推开**：

| `b` | `\|λ₀\|` | `arg λ₁` |
| :-- | :-- | :-- |
| 0 | 1.236 | **36.000°** |
| 0.382 | 0.854（已稳定） | 18.000° |
| 0.618 | 0.618 | 9.732° |

> **线性模型无法兼得**：要么保住五角星步（36°）而均匀模过载，要么压住过载而丢掉 36°。
> **——这恰恰就是为什么需要非线性 / 层级（复盘里的 ⑥）。**
