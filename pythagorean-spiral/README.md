# 五行 · 毕达哥拉斯螺旋（wuxing-math）

把「五行 = 毕达哥拉斯螺旋」这一直觉，逐层做成**可复算**的数学论证：
**几何 → 标度 → 动力学 → 非线性 → 相图 → 中医对应**。

所有结论分三层标注：**严格 / 半严格 / 结构性**。
每个数字都有对应的 `tools/make_*.py` 可重跑。

---

## 核心结论（一页）

| 层面 | 结论 | 判定 |
| :-- | :-- | :-- |
| 几何 | 每层转 72°，5 次回归（`R⁵ = I`，群 `C₅`） | 严格 |
| 几何 | 正五边形：对角线 ÷ 边长 = `φ` | 严格 |
| 几何 | 五角星自然内五边形：**36°/层、缩放 `1/φ²`、周期 10** | 严格 |
| 几何 | 五行（72°）与五角星（36°）**同族而非同曲线** | 严格 |
| 标度 | `q^Z` 离散标度不变（DSI）；对数周期 = 复临界指数 | 严格 |
| 标度 | **实检否定**：generic `C₅` 非线性模型**没有**对数周期 | 严格 |
| 标度 | 闭环：`T = 缩放 q ∘ 旋转 36°` 才有调制周期 5 | 严格 |
| 动力学 | `T² = q² e^(i72°)` ⟹ 五角星步是相生步的**平方根** | 严格 |
| 动力学 | **旋量双覆盖**：5 步复原 / 10 步复原（与 720° 同构） | 严格 |
| 动力学 | 稳定性 ⟺ `d > a`（**限 `0 ≤ d ≤ 1`**；`d > 1` 为过冲区，判据失效） | 严格（域内） |
| 非线性 | **总量饱和 `-c*X̄`** 可两全（立方饱和会把相位推到 42.17°） | 严格 |
| 相图 | 两全参数 `(a, d, c) = (1/φ, 1/φ², 1/φ³)` | 严格 |
| 相图 | **`c = a - d = χ`**（四重恒等） | 严格 |
| 中医 | θ = 0 ⟺ 「亢则害，承乃制」；「承」≡ 相克项 `b` | 结构性 |

> 一句话：**原稿抓住的是 `C₅` 与它必然携带的 `φ`；真的新东西在动力学层——
> `1/φ^k` 三幂配齐三个角色，且 `c = a - d = χ`。**
