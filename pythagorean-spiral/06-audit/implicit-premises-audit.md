# 隐含前提审计（V10）

**目的**：把标为"严格"的结论逐条写成「**前提 ⟹ 结论**」，找出**前提未被声明**的地方。
**触发**：2026-09-17 外部核查发现 §3.3 的稳定阈值依赖一个未声明的域假设（`d ≤ 1`）。
**对象**：六层结论链 34 条（G1–G6 / S1–S6 / D1–D7 / N1–N4 / P1–P9 / C1–C7）+ 各文档标注表。
**产出**：10 条待补前提（高 3 / 中 5 / 低 2），及一份"该补在哪"的清单。

> 说明：本审计**不质疑**结论的真伪，只检查**前提是否写在明处**。

---

## 一、总览

| 严重度 | 条数 | 含义 |
| :-- | :-- | :-- |
| **高** | 3 | 前提缺失会**改变结论的适用范围或数值** |
| **中** | 5 | 前提缺失会让读者**高估结论强度** |
| **低** | 2 | 前提缺失属**表述规范**问题 |
| 无问题 | 其余 | 前提已声明，或结论是纯代数/纯几何事实 |

**一句话**：六层里 **几何层与代数部分最干净**；**"标度层"与"动力学层"的前提缺失最集中**——因为它们的数值都挂在同一个未实测的量 `q` 上。

## 二、主要发现

### 🔴 高

#### A1 · `S3` 的数值依赖一个**未实测**的 `q`

| | |
| :-- | :-- |
| 原表述 | 「本结构在 `ln r` 上等距（步长 `ln q = −0.96242365`）」——标 **严格** |
| 隐含前提 | **`q = 1/φ²`**（几何骨架取值，非实测；V4 已列为待裁决） |
| 复算 | `q=0.382→ln q=−0.9624`；`q=0.35→−1.0498`；`q=0.45→−0.7985` |
| 影响 | **"等距"这个性质严格；但数值 −0.9624 完全继承 `q` 的不确定性** |
| 建议 | 改为「等距（严格）；步长 `= ln q`，取 `q=1/φ²` 时为 `−0.9624`（`q` 待实测，见 V4）」 |

#### A2 · `S4` 的"generic"**没有定义**

| | |
| :-- | :-- |
| 原表述 | 「实检：**generic `C₅` 非线性模型**没有对数周期」——标 **严格（否定结论）** |
| 隐含前提 | 一个**具体的模型族**（文档中实为该族：`x→(1−d)x+aSx` + 各向同性立方饱和，取临界线 `a=d`） |
| 影响 | 读者会把"否定"读成**对一切 `C₅` 模型**成立；实际只对该族成立 |
| 建议 | 写明族定义与参数取值；把 "generic" 改成 **"本族模型（定义见下）"** |

#### A3 · `D2`（及 D 层）是**构造**，不是推导——收卷之作已声明，**总报告未继承**

| | |
| :-- | :-- |
| 原表述 | 「`M = q·R(36°)` 的特征值 `λ = q·e^(±i36°)`」——标 **严格** |
| 真相 | **特征值计算是严格的**；但"**五行动力学就是这个 `M`**"是**构造性建模** |
| 证据 | **收卷之作 §八** 已明确写：`"五行动力学就是这组方程" | 结构性（构造性建模；需实测标定 a,d,c）` ✅ |
| 问题 | **总报告 §二 的 D 层把这条限定丢了**，读者在总报告层面看不到 |
| 建议 | 总报告 §二 D 层加一行表头说明：**"以下 D1–D7 均为「给定该方程」下的严格结论"** |

---

### 🟡 中

#### A4 · `G1/G4` 把**五行语义**与**循环次序**混在一句话里

- 原表述：「每层转 72°，5 次回归 ⟺ `R⁵=I`」标严格；「五行与五角星同族」标严格。
- 隐含前提：**"把五行的循环次序映射到 `C₅`"是一个建模选择**——`R⁵=I` 是群论事实，**与五行是什么无关**。
- 影响：容易被读成"五行在数学上**就是** `C₅`"（这正是原稿越界的地方）。
- 建议：补一句「本结论只在**循环次序**层面成立，不涉及五行的实质」。

#### A5 · `G6` 预设 `q ≠ 1`

- 原表述：「螺旋 ≠ 循环：方位有周期（5）、径向无周期」——标 **严格**。
- 复算：`q=1 → 走 5 层回到原点（是循环）`；`q=1/φ² → 半径 0.0081（是螺旋）`。
- 建议：加限定「**在 `q ≠ 1` 时**」——`q=1` 退化为闭轨。

#### A6 · `D4` 一条结论里装了**两个等级**

- 原表述：「旋量双覆盖：相生 5 步复原；五角星 5 步 180°、10 步复原（**与《旋量-太极》720° 同构**）」——整体标 **严格**。
- 真相：**"10 步复原"是严格代数事实**；**"与 720° 同构"是结构性比喻**。
- 建议：拆成两条，各自标级。

#### A7 · `N3` 的 `42.17°` 是**参数依赖**的数值

- 原表述：「立方饱和 `−c|x|²x` 会把 `arg λ1` 推到 42.17°」——标 **严格**。
- 复算（恒等式）：`cos³φ = (3cosφ + cos3φ)/4` ⟹ 立方项对 `k=1` 的有效修正 **`∝ c·A²`**
- 结论：**42.17° 不是常数**，随振幅 `A`、系数 `c` 变化。
- 建议：注明参数取值；或改述为「会产生**正比于 `A²` 的相位漂移**（该参数下为 42.17°）」。

#### A8 · `S4/S6` 的**谱检验**同样依赖未实测的 `q`

- 检验用的目标频率是 `1/|ln q|`；`q` 变则频率变（`q=0.382→1.039`；`q=0.45→1.252`）。
- 建议：与 A1 合并处理——**把 `q` 的地位一次讲清**。

---

### 🟢 低

#### A9 · `P6–P9` 预设**线性**框架

- `c = a−d ⟹ λ0 = 1` 的推导用了 `λ0 = (1−d)+a−b−c`（**线性叠加**）。
- 换成立方饱和，该等价关系**不再成立**。
- 建议：P6 表头注明「**在线性更新下**」。

#### A10 · 全局：**线性约定未集中声明**

- D1 标了"（约定）"✅，但 P6–P9、N1–N4 都共用同一约定，却分散在各节。
- 建议：在 §二 开头加一句「本层所有动力学结论共用 `λ_k = (1−d)+aω^k−bω^{2k}` 这一**线性约定**（D1）」。

## 五、**不受影响**的部分

以下结论**不依赖任何未声明前提**（要么是纯数学事实，要么前提已明写）：

- **G2**：正五边形 对角线/边长 = `φ`（纯几何）
- **D5/D6**：临界点闭式 `(1/φ, 1/φ²)` 与 `λ0 = 2/φ`（给定模型后的纯代数）
- **P1**：`1/φ^k = q^(k/2)`（代数恒等式）
- **P2–P5、P7–P9**：均为给定模型/参数后的**代数或数值**结论，且参数已逐条写明
- **N1、N2、N4**：表示论与 rank-1 论证
- **S2**：对数周期定理（纯数学）

> 也就是说：**A1–A10 不改变任何结论的数学内容，只改变"这些结论在多大范围内成立"的表述。**

---

## 六、结论

1. **没有发现第二条"§3.3 式"的硬错误**——即没有"标为严格但实际不成立"的结论。
2. 但发现 **10 处前提未写在明处**；其中 **3 处（A1/A2/A3）会让读者高估适用范围**。
3. **最该补的一条是 A3**：收卷之作已诚实声明"模型是构造性的"，但总报告汇总时丢了这条限定——**这正是 §3.3 事件同一类型的失误：限定在源头有，汇总时没带过来。**
