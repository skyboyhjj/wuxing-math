# 读解（续）："generic 模型族"到底是什么

**起因**：审计 A2 —— §十五 的否定结论写的是"**generic `C₅` 非线性模型**没有对数周期"，但**从未定义"generic"**。
**本文**：给出该族的**精确刻画**，并说明否定结论的**真实边界**。

---

## 〇、一句话答案

> **"generic" 应当读作：`混合次数`（1 次线性 + 3 次非线性）的 `C₅` 环耦合多项式族。**
> **该族不齐次 ⟹ 没有标度协变 ⟹ 不可能有 DSI ⟹ 不可能有对数周期。**
>
> **这不是"C₅ 的错"，而是"混合次数的错"**——换任何对称群，结论一样。

---

## 一、原模型与检验（复述）

```
x_i(t+1) = (1−d)·x_i + a·(Sx)_i − c·x_i³        临界线 λ_k=(1−d)+aω^k, ρ=1 ⟺ a=d
```
谱检验：在 `ln t` 上做 DFT，问 `f* = 1/|ln q| = 1.039` 处有没有峰。
§十五结果：**0.179 / 0.133**（注入对照 **0.997**）⟹ 无峰。

---

## 二、决定性检验：模型**齐次**吗？

"有 DSI"的代数前提是**标度协变**：存在 `p` 使 `F(λx) = λ^p·F(x)`。
把该式直接在原模型上测（随机 `x`，扫 `p` 取最优）：

| 模型 | `λ=0.5` 最优 `p` | 相对残差 | 判定 |
| :-- | :-- | :-- | :-- |
| **原模型**（1 次 + 3 次） | 0.823 | **0.650** | ✗ **不齐次** |
| 同上（`λ=2`） | −0.066 | **0.993** | ✗ 不齐次 |
| 同上（`λ=1/φ²`） | 0.856 | **0.692** | ✗ 不齐次 |
| **去掉立方项**（纯线性） | 1.000 | **0.000** | ✅ 齐次（`p=1`） |
| **纯立方**（`aSx³ − cx³`） | 3.000 | **0.000** | ✅ 齐次（`p=3`） |

**解析**：

```
F(λx) = λ·[(1−d)x + a·Sx]  −  λ³·c·x³
        └── ∝ λ ──┘          └── ∝ λ³ ──┘
```
**线性项按 `λ` 走、立方项按 `λ³` 走——不存在统一的 `p`。**

> **所以该模型没有"标度"这个自由度**；`q` 根本不在模型里。
> **在一个没有 `q` 的模型里，问"有没有以 `q` 为周期的振荡"，答案必然是"没有"。**

---

## 三、"generic" 的精确刻画（建议写进文档）

| 要素 | 内容 |
| :-- | :-- |
| **结构** | 5 个节点、环耦合（`S`）、**逐点多项式**非线性 |
| **参数** | `d, a, c` 为**常数**；临界线 `a = d` |
| **关键缺失** | **族中没有任何"尺度参数 `q`"**——所有耦合都是**最近邻/逐点**，**没有层级、没有跨尺度反馈** |
| **维数** | **混合**（1 次与 3 次并存）⟹ **无单一标度维数** |

**建议表述**：
> 「在本族（**混合次数的 `C₅` 环耦合模型**，定义见上式，参数 `d,a,c` 常数）中，
> 临界点附近**不存在**以 `q` 为周期的对数振荡。」

---

## 四、否定结论的**真实边界**：两条必要条件

对数周期（"幂律 + 以 `ln q` 为周期的振荡"）需要**同时**满足：

| # | 条件 | 原族 | 说明 |
| :-- | :-- | :-- | :-- |
| **(i)** | **`q`-协变**：齐次，或模型显式含 `q` | ✗ **不满足** | 混合次数 ⟹ 不可能 |
| **(ii)** | **跨尺度的持续动力学**（临界慢化穿过多层） | — | 原族在临界点**收敛**，谈不上跨尺度 |

> **原族在 (i) 上就已经出局**——所以 §十五 的否定**与 (ii) 无关，是结构性的**。

**推论**：
- 换对称群（`C₇`、`C₃`…）**只要混合次数，结论照旧否定** ⟹ 否定**不是 `C₅` 的性质**；
- **只要 (i) 成立**（齐次，或显式含 `q`），`C₅` **也可以**有 DSI ⟹ 这正是 §十六 的做法。

---

## 五、诊断升级：从"旋转 vs 标度"到"次数混合"

§15.5 的诊断是：

> 「`C₅` 是"旋转"对称（指标周期 5），不是"标度"对称。」

**这句话对，但不是操作性原因**。更精确的是：

| 层级 | 陈述 | 强度 |
| :-- | :-- | :-- |
| 对称群层 | `C₅` 是旋转对称，不是标度对称 | 正确，但**普适**（任何群都一样） |
| **函数层** | **该模型混合了 1 次与 3 次 ⟹ 不齐次 ⟹ 无 `q`-协变** | **操作性原因** ★ |

**为什么"函数层"更根本**：`C₅` 作用在**指标**上，DSI 作用在**幅度/尺度**上——两者本就独立。
**决定有没有 DSI 的，是函数是否齐次，而不是群的类型。**

---

## 六、对建模的指导（三步）

1. **要 DSI** ⟹ 必须让模型**齐次**，或**显式引入 `q`**（层级耦合）；
2. **要"幂律"** ⟹ 还需临界点附近**持续的跨尺度弛豫**（而非收敛到不动点）；
3. **`C₅` 只负责"方位周期 5"**——它**不提供**标度，两者要**分别装配**。

> 这正是 §十六 的路子：`T =（缩放 q）∘（旋转 36°）` —— **把标度显式装进动力学**。

---

## 七、标注

| 主张 | 判定 |
| :-- | :-- |
| 原模型**不齐次**（残差 ≫ 0） | **严格（数值 + 解析）** |
| 去线性项或去立方项后**精确齐次** | **严格（残差 = 0）** |
| 混合次数 ⟹ 无 `q`-协变 ⟹ **不可能**有 DSI | **严格（结构性）** |
| 否定结论**限于该族**、与 `C₅` 无关 | **严格** |
| 对数周期需 (i)+(ii) 两条 | **严格（(i) 必要、（ii) 是充分性的一部分）** |
| "只要齐次，`C₅` 也可以有 DSI" | **构造性**（§十六 给出显式构造） |
| §15.5 的诊断应升级为"次数混合" | **结构性（表述改进）** |
