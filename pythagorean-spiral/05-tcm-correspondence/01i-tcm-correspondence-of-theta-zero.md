# 对接①续九：θ=0 的中医对应——"亢则害，承乃制"与"平人"

**任务**：θ=0 的"生克平衡"对应哪种中医状态？

---

## 〇、答案

> θ=0 点的动力学是**生克精确相抵、图案不转**。
> 它在《内经》里有两处**精确**对应：
>
> 1. **《素问·六微旨大论》**：
>    「**亢则害，承乃制，制则生化，外列盛衰，害则败乱，生化大病。**」
> 2. **《素问·调经论》**：
>    「夫阴与阳，皆有俞会……**阴阳匀平，以充其形，九候若一，命曰平人。**」
>
> **定量**：**"承乃制" = `b = d`（承制强度 = 耗散率），且 `b/a = φ`（承 = φ × 亢）。**

![承制平衡与平人](../figures/chengzhi_pingren.png)

## 一、经文的"承"就是相克（严格对应）

《六微旨大论》原文把"承"列成五条：

> 相火之下，水气承之；水位之下，土气承之；土位之下，风气承之；
> 风位之下，金气承之；金位之下，火气承之；君火之下，阴精承之。

**每一行的"承"，正是克它的那一行** ⟹

```
"亢"  ≡  相生项 a
"承"  ≡  相克项 b      （"承制" = 制约）
```

**所以经文谈的不是比喻——它就是模型里的两个系数。**

## 二、θ=0 的全谱（严格，5×5 实机）

| 模式 | 模 | 相位 | 状态 |
| :-- | :-- | :-- | :-- |
| `λ0` 均匀 | **0.472136 = 2/φ³** | 0° | 衰减（稳） |
| `λ1` 相生 | **1.000000** | **0°** | **中性、实、不转** |
| `λ2` / `λ3` | 0.589512 | ±58.386° | 衰减（有转） |
| `λ4` 子病及母 | **1.000000** | **0°** | **中性、不转** |

**留意的两点**：

- `λ1 = 1` 是**实数、正**——图案**既不转也不衰**；
- `λ1 = λ4 = 1`——**生与逆生同时中性**，这正是"生克相抵"的对称态。

## 三、两个数的经文读法（严格）

| 数学条件 | 含义 | 对应经文 |
| :-- | :-- | :-- |
| `b = d` | 承制强度 = **耗散率** | 「**承乃制**」——制约恰为系统自身的耗散 |
| `b/a = φ` | 承 = **φ ×** 亢 | 「亢则害，**承乃制**」——承要压得住亢 |
| `λ1 = 1`（实、正、不转） | 生克相抵 | 「**制则生化**」——有制才有生化 |
| `λ0 = 2/φ³ < 1` | 均匀模稳 | 「**阴阳匀平**……命曰平人」 |

## 四、对照：无承制就是"害则败乱"（严格）

| 点 | `b` | 均匀模 `\|λ0\|` | 经文 |
| :-- | :-- | :-- | :-- |
| **五角星点**（但生无克） | 0 | **2/φ = 1.236（过载）** | 「**害则败乱，生化大病**」 |
| **θ=0**（承制到位） | `1/φ² = d` | 0.472（稳） | 「亢则害，承乃制，制则生化」 |

> **★ 原稿"只有相生会过载"的经文根据，就在这里。**

## 五、相位与「承/亢」之比（严格）

固定 `b = d`，扫 `a`：

| `b/a` | 0.39 | **0.62 = 1/φ** | 0.79 |
| :-- | :-- | :-- | :-- |
| `arg λ1` | −4.81° | **0°** | +3.41° |

**承不足则相位负偏，承过度则相位正偏；`承/亢 = φ` 时恰好归零。**

（这正是《素问·至真要大论》"**以平为期**"的定量版：承制过与不及都是病。）

---

## 六、一句话

> **"承乃制"的数学形式：承制强度 = 耗散率，且恰为亢的 φ 倍。**
> **"害则败乱"就是 `b = 0` 时的过载 `|λ0| = 2/φ > 1`。**
